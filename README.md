# Proyecto Sivex 🚀

**Nota:** Este proyecto depende de un backend extra. Asegúrate de tenerlo configurado y en funcionamiento para que la aplicación opere correctamente.

## 📋 Requisitos

- [Node.js](https://nodejs.org/) (versión LTS recomendada o superior)
- [NPM](https://www.npmjs.com/)

## 📥 Instalación

1. **Clona el repositorio** en tu máquina:
   ```bash
   git clone https://github.com/SIGESCAL/SIGESCALFrontEnd/tree/staging
   ```

2. **Instala las dependencias ejecutando el siguiente comando en la raíz del proyecto**:
   ```bash
   npm install
   ```

## 🚀 Ejecutar la Aplicación

Para iniciar el servidor de desarrollo, ejecuta:
   ```bash
   npm run dev
   ```
Este comando levantará el servidor de Vite con Hot Module Replacement (HMR) para facilitar el desarrollo.

## 📦 Otros Comandos Útiles

**Construir para producción:**
   ```bash
   npm run build
   ```
Este comando compila el proyecto utilizando TypeScript y Vite para generar los archivos optimizados.

**Previsualizar la aplicación en modo producción:**
   ```bash
   npm run preview
   ```
